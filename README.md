## 📋 О проекте

Веб-приложение для отображения и анализа ключевых показателей эффективности (KPI). Построено на Angular 6 с компонентной архитектурой.

### Возможности

- 📈 Отображение KPI-метрик
- 🔧 Компонентная архитектура
- 🧪 Юнит-тесты (Jasmine + Karma)

---

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm start          # или: ng serve

# Сборка (production)
npm run build      # или: ng build --prod

# Тесты
npm test           # или: ng test
```
